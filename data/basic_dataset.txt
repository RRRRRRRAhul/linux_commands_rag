LINUX BASICS KNOWLEDGE BASE
============================

Document: Linux Basics
Version: 1.0
Level: Beginner
Purpose: Knowledge source for a Linux RAG Assistant.

This document teaches basic Linux commands, file management, text processing, permissions, processes, networking, storage, archives, and package management.

Important:
Commands can behave differently depending on the Linux distribution, shell, user permissions, and installed software. Examples should be tested carefully. Commands that delete files, terminate processes, modify permissions, or install packages can have important consequences.

============================================================
SECTION 1: LINUX INTRODUCTION
============================================================

Linux is an open-source operating system kernel. Linux distributions combine the kernel with system utilities, libraries, package managers, and other software.

Examples of Linux distributions include Ubuntu, Debian, Fedora, Arch Linux, and Linux Mint.

A terminal is an interface where users enter commands. A shell reads commands and executes programs.

Common shells include Bash and Zsh. Bash is widely used on Linux systems.

A command usually has this structure:

command [options] [arguments]

Example:

ls -l /home

In this example:
- ls is the command.
- -l is an option.
- /home is an argument.

The current working directory is the directory where a command is being executed.

The home directory is the personal directory of a user. It is commonly represented by ~.

The root directory is represented by /. It is the top-level directory of the Linux filesystem.

The root user is the administrator account. The root directory and root user are different concepts.

COMMAND 1: pwd
--------------

Name:
pwd

Meaning:
Print Working Directory.

Description:
The pwd command displays the absolute path of the current working directory.

Syntax:
pwd

Example:
pwd

Example output:
 /home/rahul/projects

Common usage:
Use pwd when you are unsure which directory you are currently inside.

Important:
The output depends on the current directory of the terminal.

============================================================

COMMAND 2: ls
--------------

Name:
ls

Meaning:
List.

Description:
The ls command displays files and directories in a location.

Syntax:
ls [options] [path]

Basic example:
ls

List files in a specific directory:
ls /home

Common options:
ls -l
Displays detailed information.

ls -a
Shows hidden files and directories.

ls -h
Displays human-readable file sizes when used with a suitable listing option.

ls -la
Shows hidden files with detailed information.

Example:
ls -lah /var/log

Important:
Hidden files usually begin with a dot, such as .bashrc.

============================================================

COMMAND 3: cd
--------------

Name:
cd

Meaning:
Change Directory.

Description:
The cd command changes the current working directory.

Syntax:
cd [directory]

Examples:
cd /home
cd /tmp
cd ~

Go to the parent directory:
cd ..

Go to the previous directory:
cd -

Go to the home directory:
cd

Important concepts:
- / is the root directory.
- ~ represents the current user's home directory.
- .. represents the parent directory.
- . represents the current directory.

Example workflow:
pwd
cd /tmp
pwd
cd ..
pwd

============================================================

COMMAND 4: mkdir
-----------------

Name:
mkdir

Meaning:
Make Directory.

Description:
The mkdir command creates one or more directories.

Syntax:
mkdir [options] directory_name

Example:
mkdir projects

Create multiple directories:
mkdir frontend backend docs

Create nested directories:
mkdir -p project/src/components

The -p option creates parent directories if they do not exist.

Example:
mkdir -p linux-rag/data/raw

Important:
mkdir normally reports an error if the target directory already exists, unless appropriate options are used.

============================================================

COMMAND 5: rmdir
-----------------

Name:
rmdir

Meaning:
Remove Directory.

Description:
The rmdir command removes empty directories.

Syntax:
rmdir directory_name

Example:
rmdir old_folder

Remove nested empty directories:
rmdir -p parent/child

Important:
rmdir only removes empty directories. It does not remove directories containing files.

To remove a directory containing files, other commands such as rm may be used, but they must be used carefully.

============================================================

COMMAND 6: touch
-----------------

Name:
touch

Description:
The touch command creates an empty file if the file does not exist. If the file exists, it can update its timestamps.

Syntax:
touch filename

Examples:
touch notes.txt
touch app.py
touch file1.txt file2.txt

Create a file inside a directory:
touch project/README.md

Important:
touch does not open the file or add content to it.

Example:
touch hello.txt
ls -l hello.txt

COMMAND 7: cp
---------------

Name:
cp

Meaning:
Copy.

Description:
The cp command copies files or directories.

Syntax:
cp [options] source destination

Copy a file:
cp notes.txt backup.txt

Copy a file into a directory:
cp notes.txt /tmp/

Copy a directory recursively:
cp -r project project_backup

Common options:
cp -r
Copies directories and their contents.

cp -i
Asks before overwriting files in supported situations.

cp -v
Shows the operations being performed.

Example:
cp -rv src backup_src

Important:
When copying directories, recursive copying is generally required.

============================================================

COMMAND 8: mv
---------------

Name:
mv

Meaning:
Move.

Description:
The mv command moves files and directories. It is also used to rename them.

Syntax:
mv [options] source destination

Rename a file:
mv old.txt new.txt

Move a file:
mv notes.txt documents/

Move and rename:
mv app.py project/main.py

Common options:
mv -i
Asks before overwriting files in supported situations.

mv -v
Displays the operations being performed.

Important:
The effect of mv depends on the source and destination paths.

COMMAND 9: rm
---------------

Name:
rm

Meaning:
Remove.

Description:
The rm command removes files and can remove directories with suitable options.

Syntax:
rm [options] file

Remove a file:
rm notes.txt

Remove multiple files:
rm file1.txt file2.txt

Remove a directory and its contents:
rm -r old_project

Common options:
rm -r
Recursively removes directories and their contents.

rm -i
Prompts before removal in supported situations.

rm -f
Forces removal in supported situations.

Important:
rm normally does not provide a recycle bin. Deleted data may not be easily recoverable.

Be extremely careful with recursive removal and paths such as / or /*.

COMMAND 10: find
-----------------

Name:
find

Description:
The find command searches for files and directories in a directory hierarchy.

Syntax:
find [starting_path] [conditions] [actions]

Find all files in the current directory:
find .

Find a file by name:
find . -name "notes.txt"

Find Python files:
find . -name "*.py"

Find directories:
find . -type d

Find regular files:
find . -type f

Find files under /tmp:
find /tmp -type f

Find files by name, case-insensitively:
find . -iname "readme.md"

Common conditions:
-name
Matches a name pattern.

-type f
Matches regular files.

-type d
Matches directories.

Important:
find searches recursively by default from the starting path.

COMMAND 11: cat

The cat command displays file contents and can concatenate multiple files.

COMMAND 13: head
-----------------

Name:
head

Description:
The head command displays the beginning of a file or input.

Syntax:
head [options] [file]

Display the first 10 lines:
head file.txt

Display the first 5 lines:
head -n 5 file.txt

Display the first 20 lines:

COMMAND 14: tail
-----------------

Name:
tail

Description:
The tail command displays the end of a file or input.

Syntax:
tail [options] [file]

Display the last 10 lines:
tail file.txt

COMMAND 15: grep
-----------------

Name:
grep

Meaning:
Global Regular Expression Print.

Description:
The grep command searches for lines matching a pattern in text.

Syntax:
grep [options] pattern [file]

Search for a word:
grep "error" app.log

Case-insensitive search:
grep -i "error" app.log

Show line numbers:
grep -n "error" app.log

Search recursively:
grep -r "TODO" project/

Invert the match:
grep -v "success" app.log

Count matching lines:
grep -c "error" app.log

Common options:
-i
Ignore case.

-n
Show line numbers.

-r
Search recursively.

-v
Show lines that do not match.

-c
Count matching lines.

Example:
grep -n -i "failed" /var/log/auth.log

Important:
grep works with patterns. Regular expressions can be used for more advanced searches.

============================================================

COMMAND 16: sort
-----------------

Name:
sort

Description:
The sort command sorts lines of text.

Syntax:
sort [options] [file]

Sort lines alphabetically:
sort names.txt

Sort in reverse order:
sort -r names.txt

Sort numerically:
sort -n numbers.txt

Sort and remove duplicate adjacent lines:
sort names.txt | uniq

Common options:
-r
Reverse the sorting order.

-n
Sort numerically.

-f
Ignore case in supported sorting behavior.

Example:
sort -n scores.txt

Important:
sort normally processes lines as text. Numeric sorting uses -n.

============================================================

COMMAND 17: uniq
-----------------

Name:
uniq

Description:
The uniq command removes or reports repeated adjacent lines.

Syntax:
uniq [options] [file]

Remove adjacent duplicate lines:
uniq names.txt

Count repeated adjacent lines:
uniq -c names.txt

Show only duplicated adjacent lines:
uniq -d names.txt

Common usage:
sort names.txt | uniq

Important:
uniq compares adjacent lines. To remove duplicates throughout an unsorted file, sorting first is often necessary.

Count words:

COMMAND 19: cut
-----------------

Name:
cut

Description:
The cut command extracts selected sections from each line of text.

Syntax:
cut [options] [file]

Extract the first field separated by a colon:
cut -d ':' -f 1 /etc/passwd

Extract characters:
cut -c 1-5 file.txt

Extract a comma-separated field:
cut -d ',' -f 2 data.csv

Common options:
-d
Specify the delimiter.

-f
Select fields.

-c
Select characters.

cut is useful for simple structured text. More complex transformations may require awk or other tools.

COMMAND 20: tr
----------------

Name:
tr

Meaning:
Translate or Delete Characters.

Description:
The tr command translates, replaces, or deletes characters from standard input.

Syntax:
tr [options] SET1 [SET2]

Convert lowercase to uppercase:
echo "hello" | tr 'a-z' 'A-Z'

Replace spaces with underscores:
echo "hello world" | tr ' ' '_'

Delete digits:
echo "abc123" | tr -d '0-9'

Delete newline characters in a simple input:
tr -d '\n' < file.txt

Common options:
-d
Delete characters.

-s
Squeeze repeated characters.

Important:
tr normally reads from standard input and writes to standard output.

SECTION 5: FILE PERMISSIONS AND USERS

COMMAND 26: chmod
------------------

Name:
chmod

Meaning:
Change Mode.

Description:
The chmod command changes file and directory permissions.

Syntax:
chmod [options] mode file

Symbolic permission example:
chmod u+x script.sh

This adds execute permission for the owner.

Numeric permission example:
chmod 755 script.sh

Meaning of 755:
- Owner: read, write, execute.
- Group: read, execute.
- Others: read, execute.

Common symbolic forms:
u
User or owner.

g
Group.

o
Others.

a
All categories.

r
Read permission.

w
Write permission.

x
Execute permission.

Examples:
chmod u+x script.sh
chmod g-w file.txt
chmod o+r document.txt

Important:
Changing permissions affects who can read, write, or execute a file. Be careful with permissions on sensitive files and directories.

============================================================

COMMAND 27: chown
------------------

Name:
chown

Meaning:
Change Owner.

Description:
The chown command changes the owner of files and directories.

Syntax:
chown [options] owner[:group] file

Example:
sudo chown rahul file.txt

Change owner and group:
sudo chown rahul:developers project/

Recursive ownership change:
sudo chown -R rahul:developers project/

Important:
Changing ownership often requires administrator privileges. Recursive changes can affect many files.

COMMAND 33: kill
------------------

Name:
kill

Description:
The kill command sends a signal to a process.

Syntax:
kill [signal] PID

Send the default termination signal:
kill 1234

Send SIGTERM:
kill -TERM 1234

Send SIGKILL:
kill -KILL 1234

Important:
The command name is kill, but it sends signals. SIGTERM requests termination and allows a process to clean up. SIGKILL forces termination and cannot be caught by the target process.

Use process IDs carefully.

apt

SECTION 11: COMMON LINUX CONCEPTS
============================================================

1. Absolute path

An absolute path starts from the root directory.

Example:

2. Relative path

A relative path is interpreted from the current working directory.

Example:
projects/app.py

3. Standard input

Standard input is commonly represented by file descriptor 0. It is the input stream used by commands.

4. Standard output

Standard output is commonly represented by file descriptor 1. It is where normal command output is written.

5. Standard error

Standard error is commonly represented by file descriptor 2. It is used for error messages.

6. Output redirection

The > operator writes output to a file and normally overwrites the file.

Example:
echo "Hello" > output.txt

The >> operator appends output.

Example:
echo "World" >> output.txt

7. Pipe

The pipe operator | sends the standard output of one command to the standard input of another.

Example:
ls | grep ".txt"

8. Environment variables

Environment variables store values used by processes and shells.

Examples:
HOME
PATH
USER
SHELL

Display a variable:
echo "$HOME"

Display environment variables:
env

9. Exit status

Commands return an exit status. A common convention is 0 for success and a nonzero value for failure.

Display the previous command's exit status in Bash:
echo $?

10. Wildcards

The * wildcard can match multiple characters in shell pathname expansion.

Example:
ls *.txt

The ? wildcard can match one character in common shell pathname expansion.

Example:
ls file?.txt

SECTION 12: PRACTICAL COMMAND WORKFLOWS

WORKFLOW 1: CREATE A PROJECT DIRECTORY

mkdir -p linux-project/data
cd linux-project
touch README.md
pwd
ls -la

Explanation:
This workflow creates a project directory, enters it, creates a README file, and checks the current location and contents.

============================================================

WORKFLOW 2: FIND PYTHON FILES

find . -type f -name "*.py"

Explanation:
This searches recursively from the current directory for regular files ending in .py.

============================================================

WORKFLOW 3: SEARCH LOGS FOR ERRORS

grep -n -i "error" app.log

Explanation:
This searches app.log for error text without considering letter case and displays matching line numbers.

============================================================

WORKFLOW 4: COUNT LINES IN A FILE

wc -l linux_basics.txt

Explanation:
This counts the number of lines in the knowledge document.

============================================================

WORKFLOW 5: INSPECT DISK USAGE

df -h
du -sh .

Explanation:
df -h shows filesystem space. du -sh shows the estimated space used by the current directory.

============================================================

WORKFLOW 6: INSPECT A RUNNING PROCESS

ps aux | grep python

Explanation:
This lists processes and searches the output for python. The grep command itself may also appear in the output.

============================================================

WORKFLOW 7: CREATE AN ARCHIVE

tar -czf project.tar.gz project/

Explanation:
This creates a gzip-compressed tar archive containing the project directory.

============================================================

WORKFLOW 8: CHECK NETWORK CONNECTIVITY

ping -c 4 example.com
curl -I https://example.com

Explanation:
The first command tests ICMP reachability. The second requests HTTP headers. They test different parts of network communication.
